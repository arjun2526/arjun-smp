# ARJUN SMP — Phase 1

## Phone-friendly upload (all files are in the root)
Upload these four files directly into the ROOT of your GitHub repository:
- `index.html`
- `style.css`
- `app.js`
- `README.md` (optional)

Do not create folders. Keep all files together in the repository root.

## Enable GitHub Pages
1. Open your repository on GitHub.
2. Go to Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Open the Pages URL shown by GitHub.

## Phase 1 status
This is a frontend dashboard preview. It does not yet connect to or control the Minecraft server. Console output and server actions are demonstrations; browser-stored property edits are local to that browser. Plugin names shown are planned examples, not proof that they are installed.

Phase 2 will add secure admin authentication and the backend connection. Never put passwords, Supabase service-role keys, tunnel tokens, or other secrets in these public frontend files.
